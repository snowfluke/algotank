# 8. The pm2 alternative

Use pm2 in place of systemd only if you already run pm2 on the server. Run the game under one of the two, never both: the arenas live in the memory of one process, and two processes on one data folder damage it.

`deploy/ecosystem.config.cjs` runs one process in fork mode (`exec_mode: "fork"`, `instances: 1`). pm2 picks cluster mode for Bun when `instances` is set, unless `exec_mode` says otherwise ([pm2 configuration file](https://pm2.keymetrics.io/docs/usage/application-declaration/)). The file reads `/etc/algotank/env`, because pm2 has no option for an environment file. It sets `kill_timeout` to 30 s, so pm2 waits for the server's shutdown before it sends SIGKILL.

Without systemd, the process has none of the hardening of `deploy/algotank.service`.

Nothing on this page was tested on a server.

## Set up pm2

Do sections A to F of `02-first-deploy.md` first, but skip the systemd unit `algotank.service` in step D5.

1. Install Node.js and pm2. pm2 itself runs on Node.js.

   ```sh
   sudo apt install -y nodejs npm && sudo npm install -g pm2
   ```

2. Make the data folder and pm2's folder for the user `algotank`. systemd does not make the data folder in this setup.

   ```sh
   sudo install -d -m 0700 -o algotank -g algotank /var/lib/algotank /var/lib/algotank-pm2
   ```

3. Install the first release. The script restarts the game with pm2 in place of systemd.

   ```sh
   sudo SERVICE_MANAGER=pm2 algotank-release /tmp/algotank-release.tar.gz
   ```

4. Save pm2's process list.

   ```sh
   sudo -u algotank HOME=/var/lib/algotank-pm2 pm2 save
   ```

5. Make pm2 start at boot. The command prints a second command. Run that second command ([pm2 startup](https://pm2.keymetrics.io/docs/usage/startup/)).

   ```sh
   sudo -u algotank HOME=/var/lib/algotank-pm2 pm2 startup systemd -u algotank --hp /var/lib/algotank-pm2
   ```

## Use pm2

| Task | Command |
|------|---------|
| Install a release | `sudo SERVICE_MANAGER=pm2 algotank-release /tmp/algotank-release.tar.gz` |
| Show the status | `sudo -u algotank HOME=/var/lib/algotank-pm2 pm2 status` |
| Show the log | `sudo -u algotank HOME=/var/lib/algotank-pm2 pm2 logs algotank` |
| Stop the game | `sudo -u algotank HOME=/var/lib/algotank-pm2 pm2 stop algotank` |
| Start the game | `sudo -u algotank HOME=/var/lib/algotank-pm2 pm2 start algotank` |

In the other sections of this runbook, use these commands in place of `systemctl` and `journalctl -u algotank`.
