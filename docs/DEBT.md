# Debt and known limits

This file lists every deliberate shortcut and known limit that remains in the code. A `ponytail:` comment in the code marks a shortcut. Run `grep -rn "ponytail:" apps packages` to find them. The line numbers below were correct on 2026-11-14. When you clear a row, delete it here and delete its comment in the code.
